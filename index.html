Definición Matemática

Phi (φ) es la proporción áurea, un número irracional que satisface:

// Ecuación definitoria φ² = φ + 1 φ = (1 + √5) / 2 φ ≈ 1.6180339887498948482045…

Aparece en la sucesión de Fibonacci: el cociente de términos consecutivos converge a φ.

Representación Digital

Entidades HTML:

<!-- Phi minúscula --> &phi; → φ &varphi; → ϕ <!-- Phi mayúscula --> &Phi; → Φ

Unicode: U+03C6 (φ), U+03D5 (ϕ), U+03A6 (Φ)

LaTeX: \varphi → φ, \Phi → Φ

Atajos de Teclado

Windows:

  • ALT + 966 (teclado numérico) → φ
  • ALT + 934 → Φ

macOS:

  • ⌥ Option + F → φ
  • ⌥ Option + Shift + F → Φ

Linux:

  • Ctrl + Shift + U, 03C6, Enter → φ
